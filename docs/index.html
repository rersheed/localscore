How to install

LocalScore isn't on the Play Store yet, so you install it straight from here. It takes a minute.

  1. 1
    Download
    Tap the green button and wait for LocalScore.apk to finish downloading.
  2. 2
    Allow the install
    Open the file. If your phone asks, tap Settings and allow installs from your browser or Files app.
  3. 3
    Install and open
    If Play Protect shows a warning, tap More details → Install anyway. That appears for any app not from the Play Store.
    If the app won't install, use the older-phone version.
